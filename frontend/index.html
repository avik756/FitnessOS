            Backup & restore

            Export your records before relying on this local app for meaningful personal data.

            Download and restore

            Download a JSON copy of sets, favorites, body and calorie entries, profile measurements, and workout templates. Restore previews the file and accepts it only when this database has no records. The backup also includes the daily journal, food library, workout sessions, and photos. Use Unlock photo export below before downloading a library that contains images. The downloaded JSON is not encrypted. Account credentials are not exported.
